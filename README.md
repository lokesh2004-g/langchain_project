# YouTube Chatbot with LangChain

A chatbot that uses YouTube video transcripts to answer user queries with LangChain.

## Features

- Extracts YouTube video transcripts.
- Processes with LangChain for responsive Q&A.
- Simple setup and usage.

## Requirements

- Python 3.x
- LangChain
- youtube-transcript-api
- hugging face (or other LLMs)
